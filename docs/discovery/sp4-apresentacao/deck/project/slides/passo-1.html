O QUE ACONTECE

  • O hook cria a branch com ws start, a partir da ws/sync, sincronizada com o main de cada repo.
  • O Atlas é atualizado nos repos com mudança relevante. Pode levar mais de 20 minutos.
  • A spec nasce em specs/ws-NNN-<nome>/.

VOCÊ VÊ

A spec em linguagem de negócio, para revisar.

Harness WMS · 7/29

Você descreve a feature como pediria a um colega. O hook do Spec Kit faz o resto: sincroniza o workspace, cria a branch e atualiza o Atlas. Não crie a branch nem a pasta da spec à mão. Se a demanda cita um sistema fora do workspace, o agente para e oferece seguir com ele como externo ou parar e pedir a inclusão. Se o hook parar, nenhuma spec é criada: a camada 2 explica cada erro desta etapa. Tempo: 2 min
