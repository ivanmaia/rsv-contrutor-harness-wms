Harness WMS · 5/28

As três peças, nas palavras do README. Workspace: os repos do Azure DevOps num só lugar; a raiz é o harness, o ferramental para desenvolver com IA. Spec Kit: o fluxo da feature, com comandos próprios para bug e refactor. Atlas: o mapa entre os repos, os docs de cada um e o impacto de mudar uma tabela, uma proc, um endpoint ou uma fila. Tempo: 1,5 min
