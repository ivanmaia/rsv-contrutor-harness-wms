Harness WMS · 25/28

O ws é o script do workspace: roda como tools/ws/ws seguido do comando, no Git Bash, na raiz. No fluxo normal você não chama quase nenhum: o ws start vem pelos hooks de início e o ws push pelo envio no fim. O ws sync serve para atualizar uma branch que ficou parada enquanto o main andou: rode tools/ws/ws sync e depois git merge --no-edit ws/sync, como na camada 2. O ws refactor pendentes lista as fatias de desacoplamento e o que falta em cada uma. Os ws atlas são chamados pelas skills do Atlas e pelos hooks; à mão, só para diagnóstico. A exceção é o ws atlas mapas na instalação das ferramentas do Atlas, na camada 3. Tempo: 1,5 min
