Harness WMS · 21/24

O ws é o script do workspace: roda como tools/ws/ws seguido do comando, no Git Bash, na raiz. No fluxo normal você não chama nenhum deles: o ws start vem pelo hook do /speckit-specify e o ws push pelo /speckit-ws-commit-push. Os ws atlas são chamados pelas skills do Atlas e pelos hooks; à mão, só para diagnóstico. A exceção é o ws atlas mapas na instalação das ferramentas do Atlas, na camada 3. Tempo: 1,5 min
