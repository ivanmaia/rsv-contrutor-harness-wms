Quando dá errado

Essa parte da documentação do harness é organizada por etapa. Procure pela mensagem: ws: erro: o comando parou; ws: aviso: ele seguiu, mas avisa.

ws: erro: há mudanças não commitadas; faça commit ou stash antes

Faça commit, guarde (git stash) ou descarte, e rode o mesmo /speckit-specify de novo.

ws: erro: ws-commit-push não roda no <main>; use a branch da feature

Volte para a branch da feature (git switch <branch>) e rode de novo.

ws: aviso: o mapeamento falhou em <repos>; esses repos continuam pendentes

Siga com a feature: ele é tentado de novo no próximo /speckit-specify.
