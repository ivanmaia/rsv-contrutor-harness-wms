Consultar é o uso do dia a dia; durante o specify e o plan o agente já consulta sozinho. Atualizar à mão é raro, e tem um cuidado: o /atlas-atualizar trabalha numa branch descartável criada a partir do main, então precisa da árvore limpa e termina no main. Rode fora de uma feature. As atualizações vão para a branch atlas/atualizacao, que tem PR próprio. Detalhes na camada 3. Tempo: 1,5 min
