Três cenas do dia a dia. Impacto: o Atlas responde quem lê ou grava uma tabela, uma proc, um endpoint ou uma fila. Branch: o /speckit-specify cria a branch no workspace, que reúne todos os repos. Envio: o /speckit-ws-commit-push faz o commit e envia a branch para cada repo que mudou; os PRs seguem o fluxo normal de cada time. Tempo: 1,5 min
