Harness WMS · 23/63

Depois da homologação, você roda o /ws-pr-main na branch da entrega. O agente roda ws pr plano main, que avisa se algum PR para o ramo de teste ainda está aberto (não bloqueia; confirme a homologação). Pede confirmação e o card de novo, sugerindo o mesmo. Com o sim, roda ws pr abrir main --card n. Se a branch de origem foi apagada ao completar o PR de teste, o harness a recria a partir do PR completado. Depois posta no espaço de produção. Enquanto a URL de produção estiver vazia, o ws mostra o texto para você colar. Ainda não validado no real: o ws pr abrir main e a recriação da branch. Tempo: 1,5 min
