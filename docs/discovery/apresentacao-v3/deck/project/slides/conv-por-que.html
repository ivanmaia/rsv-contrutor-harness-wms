Harness WMS · 43/63

Abra com a pergunta: o que o agente sabe do seu repo quando você pede uma feature? O harness já usa o que o repo escreve em três momentos. Na implementação, a regra 1 do AGENTS.md manda ler os arquivos de instrução do repo antes de mexer, sem contar com o carregamento automático. No plano, o template registra por repo as instruções lidas, a constitution do repo, a stack e os comandos exatos de build e testes. Na revisão, o /ws-pr-review lê constitution, AGENTS.md e docs/convencoes.md de cada repo e usa isso no ponto de conformidade. Quando o repo não documenta stack e comandos, o agente os deduz a cada plano; só o AWX e o Fly documentam. O Atlas ajuda, mas não substitui as convenções do time. Tempo: 1,5 min
