Harness WMS · 30/63

O plano é o ponto mais barato para corrigir direção. Por repo, o template registra as instruções do repo que o agente leu (CLAUDE.md, AGENTS.md, copilot-instructions, docs/convencoes.md, docs/adr/), a constitution do repo (no AWX, conflito com a do workspace vira pergunta ao humano), a stack, os comandos exatos de build e testes e os contratos com outros sistemas pelo índice de impacto. Confira principalmente os comandos: se estiverem errados, a verificação de cada repo mais adiante também estará. Simplicidade é a constitution VI: a menor mudança que atende a spec, sem refatoração fora do escopo. Decisão relevante vira ADR aprovado por humano (constitution IV): no repo, se for só dele; em docs/adr/ do harness, se cruza repos. A ponte: só AWX e Fly documentam stack e comandos; nos outros 16 repos o agente deduz a cada plano. É o assunto da Parte 2. Fontes: plan-template, constitution III, IV, VI, AGENTS.md regra 2. Tempo: 1,5 min
