Harness WMS · 25/63

O fluxo inteiro numa tela. Rode um comando de cada vez e leia o que ele devolve antes de seguir. Os passos 1 a 8 são a feature até o envio; o 9 é a oferta dos PRs para homologação (um sim e o número do card); o 10 é a promoção para o main depois que você decide que a homologação passou; o 11 é completar os PRs, com o do workspace por último e sem apagar a branch de origem. O passo 2 só existe se houver dúvidas. Tempo: 1,5 min
