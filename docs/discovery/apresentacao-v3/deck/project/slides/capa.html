Versão 3: entregar melhor e melhorar o harness e os repos

Outubro de 2026

Abertura. Esta é a terceira versão da apresentação do harness, com os nomes de comando do SP8. A sessão tem duas metas: primeiro, mostrar tudo o que você faz para se beneficiar do harness e entregar com mais eficiência e qualidade, do setup aos PRs e à revisão; segundo, mostrar o que cada time pode fazer para melhorar o harness e os próprios repos, com ênfase nas convenções e definições que cada repo precisa ter. A sessão dura cerca de 75 minutos, até 80, com as perguntas no fim. Não é uma aula prática: o uso vem com a documentação, começando pelo README do workspace. Tempo: 1 min
