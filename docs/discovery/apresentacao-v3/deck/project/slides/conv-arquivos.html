Harness WMS · 44/63

Estes são os arquivos que o harness procura dentro de repos/<repo>/ (AGENTS.md regra 1; ADR 0001, adendo 4): CLAUDE.md, AGENTS.md, .github/copilot-instructions.md, docs/convencoes.md, docs/adr/ e a constitution do repo (em .specify/memory/constitution.md ou docs/constitution.md). Hierarquia: a constitution e o AGENTS.md da raiz governam o que cruza repos e o jeito de trabalhar do agente; dentro do repo, as instruções dele valem para o código dele. Se houver conflito, o agente para e pergunta a um humano. O princípio da ADR 0001: o harness fica só no workspace; nos repos ficam só convenções, regras, acordos e ADRs específicos do repo. Esses arquivos podem ser editados nos repos; o que o ws push recusa é .specify/, specs/ e .claude/skills/speckit-*. Tempo: 1,5 min
