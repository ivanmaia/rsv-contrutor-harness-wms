O QUE VOCÊ REVISA

O agente escreve; você decide.

Corrigir na spec e no plano é mais barato que corrigir no código.

Nada segue sem você ler.

O build e os testes de cada repo são a régua.

Harness WMS · 28/63

O fio desta parte: o agente produz spec, plano, tarefas e código, mas cada etapa tem um ponto em que você lê e decide. Três ideias. Primeira, o custo: um erro na spec ou no plano custa uma frase para corrigir; o mesmo erro no código custa retrabalho e revisão. Segunda, nada segue sem leitura: o agente para entre os comandos justamente para você ler o que ele devolveu; rode um comando por vez. Terceira, a régua é objetiva: o build e os testes do próprio repo, não a opinião do agente. Nos próximos quatro slides percorremos as etapas: spec e clarify, plano, tarefas até converge, e o envio. Tempo: 1 min
