Harness WMS · 29/63

Na spec, leia como leria o texto de um colega: linguagem de negócio, sem decisão técnica. A seção "Repos afetados" é obrigatória no template. Quando a feature toca um contrato (endpoint HTTP, fila, tabela, view ou procedure compartilhada), os consumidores afetados vêm do índice de impacto do Atlas e entram na lista; é a regra II da constitution. Se a feature cita um sistema fora do workspace, o agente pergunta se segue como externo ou se para e pede a inclusão; a linha fica "- externo: sistema: o que a feature espera dele". Não indique a pasta do sistema ao agente (regra 7 do AGENTS.md). Uma mudança numa feature existente vai na mesma spec, que vira uma living spec com tabela de revisões. O clarify só roda se o agente disser que há dúvidas: responda tudo agora, evita retrabalho depois. Fontes: constitution II, spec-template, AGENTS.md regra 7, camada 3. Tempo: 1,5 min
