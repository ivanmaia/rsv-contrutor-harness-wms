As peças, nas palavras do README, com as duas novas do SP7. Workspace: os repos do Azure DevOps num só lugar, cada um como subtree em repos/; a raiz é o harness, o ferramental para desenvolver com IA. Spec Kit: o fluxo da feature, com comandos próprios para bug e refactor. Atlas: o mapa entre os repos, os docs de cada um e o impacto de mudar uma tabela, uma proc, um endpoint ou uma fila. O comando ws: ele já enviava os repos (ws push); agora também abre os PRs (ws pr plano e ws pr abrir) e busca o PR para a revisão (ws pr revisao e ws pr comentar), que a skill /ws-pr-review usa. Tempo: 1 min
