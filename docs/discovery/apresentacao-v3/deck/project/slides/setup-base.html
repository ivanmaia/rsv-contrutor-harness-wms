Harness WMS · 8/63

Faça uma vez por máquina, nesta ordem. 1) Claude Code: no PowerShell, irm https://claude.ai/install.ps1 | iex; abra um terminal novo e rode claude; o login é pelo navegador no primeiro uso. 2) Git for Windows: os scripts do workspace rodam no Git Bash, então comandos como git e tools/ws/ws vão nele, na raiz do workspace. 3) Caminhos longos, com o PowerShell como administrador (o agente não consegue fazer isso; o Windows responde Acesso ao Registro solicitado não é permitido): Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem' -Name LongPathsEnabled -Value 1 -Type DWord. Vale do Windows 10 1607 em diante; reabra os terminais. O core.longpaths do clone só vale para o git; Python, .NET e Node também precisam. 4) Clone completo: git clone -c core.longpaths=true -c core.autocrlf=false https://dev.azure.com/ARECO/AReCO/_git/industria-logistica.wms.workspace. Na primeira vez o Git Credential Manager pede o login do Azure DevOps, e a conta precisa poder criar branch nos repos do workspace. 5) cd industria-logistica.wms.workspace e claude. Se o claude não for reconhecido, feche e abra o terminal. Tempo: 2 min
