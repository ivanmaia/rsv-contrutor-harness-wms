2. Login com PAT

Esse setup é novo e serve para o harness abrir e revisar PRs. Instale o Azure CLI e a extensão azure-devops. Depois rode az devops login uma vez e cole um PAT; não é o az login. Escopos do PAT: Code (Read and write) e Work Items (Read). Sem o Work Items (Read), os PRs abrem, mas a mensagem do Chat sai só com o número do card, sem o título. O ws pr é Python, só biblioteca padrão; a doc da camada 1 não fixa a versão mínima (as ferramentas do Atlas pedem Python 3.10 ou mais). Dica de sessão: rode o az devops login num terminal seu; pelo ! do Claude Code ele trava no prompt do PAT. Sem o az autenticado o harness avisa e não abre nada, e mostra os links pullrequestcreate para você abrir à mão. Tempo: 1,5 min
