Harness WMS · 4/63

Cinco cenas do dia a dia. Impacto: o Atlas responde quem lê ou grava uma tabela, uma proc, um endpoint ou uma fila. Branch: o /speckit-specify cria a branch no workspace, que reúne todos os repos. Envio: o /ws-commit-push faz o commit e envia a branch para cada repo que mudou. As duas linhas novas vêm do SP7: no fim do envio o harness oferece abrir os PRs (um por repo mais o do workspace) e postar o aviso no Google Chat; a política de PR continua sendo de cada repo. Na revisão, o /ws-pr-review lê o PR do workspace e revisa o workspace e as subtrees juntos, em vez de PR por PR. Tempo: 1,5 min
