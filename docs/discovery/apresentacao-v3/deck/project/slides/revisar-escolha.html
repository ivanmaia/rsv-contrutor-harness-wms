Harness WMS · 40/63

A lista vem ordenada de alta para baixa gravidade, no formato número, ponto, gravidade, repo e PR, arquivo e linha, título, com o texto do achado. Você diz quais números publicar e pode editar o texto antes. Sem escolha, nada é publicado, e "todos" nunca é presumido: é um dos antiobjetivos do design (comentário publicado sem escolha do revisor). A publicação roda tools/ws/ws pr comentar com a credencial do revisor; código de repos/repo vai no PR do repo, o resto no do workspace, e achado sem linha ou fora do diff vira comentário geral. Rodar de novo depois de uma correção não repete os achados já publicados (o id é um sha1 de ponto, arquivo e título). O harness não aprova, não reprova e não vota. Tempo: 1,5 min
