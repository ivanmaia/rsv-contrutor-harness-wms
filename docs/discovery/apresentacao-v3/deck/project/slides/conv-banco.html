O ponto 5 (banco) do /ws-pr-review olha .sql e migrações (EF Core Migrations, Flyway etc.) e exige que cada script declare a ordem de execução e tenha rollback, apontando o que não é seguro repetir ou reverter. Hoje nenhum repo declara essa convenção, então o revisor não tem contra o que conferir. Os cinco itens são a recomendação do time do harness, não uma regra existente; o repo escolhe a forma (prefixo numérico ou data no nome, ou o mecanismo das migrações) desde que escreva. Número pelo levantamento de 22/10: 11 repos com .sql; 3 com algum arquivo de rollback (autenticacao com 2, picking.backend com 11 e servidor com 116); os que mais têm .sql são servidor (630), ecommerce.backend (122) e picking.backend (81).
