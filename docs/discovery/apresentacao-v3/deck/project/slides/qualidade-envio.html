Harness WMS · 32/63

A regra é a constitution III: cada repo afetado passa no próprio build e nos próprios testes, com as ferramentas dele; a entrega só termina quando todos passam (AGENTS.md, regra 6). Se algo falhar no envio, não contorne a guarda nem use git push ou git subtree. No bug, o /speckit-bug-test só diz verified se de fato conferiu. Partial significa que parte não foi verificada, por exemplo um repo sem testes (hoje 5 repos não têm testes encontrados). Failed significa que o sintoma continua. Aceitar um partial é decisão sua, e o PR do repo é o lugar para o time conferir o que faltou. Tempo: 1,5 min
