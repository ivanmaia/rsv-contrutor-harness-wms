Harness WMS · 31/63

Tasks: confira se cada repo tem a tarefa de verificação de build e testes com as ferramentas dele, e se as tarefas do workspace estão marcadas como [workspace]. Analyze: requisito sem tarefa significa que algo será esquecido; tarefa sem requisito significa escopo extra. Implement: o agente lê as instruções do repo antes de mexer; você acompanha e revisa como código de colega. Se ele propuser mudar o harness (tools, .specify, .claude, AGENTS.md), recuse e registre. Segredo: nada de novo em spec, doc ou código; os que já existem são só registrados (constitution V). Converge: confere o código contra a spec e acrescenta tarefas se faltar algo; repita implement e converge até não surgir tarefa nova. O commit-push avisa se há tarefas pendentes. Tempo: 1,5 min
