Recomendado, não obrigatório. Sem as ferramentas do Atlas o fluxo funciona, mas o agente navega com grep e ast-grep. Ordem: WSL com Ubuntu (como administrador); o codebase-memory-mcp, que roda no WSL, instalado no Git Bash na raiz com bash tools/atlas/instala-cbm.sh (versão 0.11.0); uv e Graphify para os frontends; ast-grep via npm, que precisa do Node.js; e por fim gerar os mapas com tools/ws/ws atlas mapas --todos. O Graphify cobre os quatro frontends (app.frontend, ecommerce.frontend, picking.frontend e o Fly) e o codebase-memory cobre os outros 14. Confira em /mcp que codebase-memory e graphify-frontends aparecem conectados.
