PASSO 11 · COMPLETAR OS PRs

O PR do workspace, por último.

  • Complete os PRs dos repos e, por último, o do workspace. Vale nos dois destinos.
  • Não apague a branch de origem ao completar para o homolog: o PR para o main sai dela.
  • A política de PR e os revisores são de cada repo.

Harness WMS · 24/63

Este é o passo que o harness não faz por você: ele abre os PRs, mas quem completa é o time. Ordem: primeiro os PRs dos repos, depois o do workspace; nada impõe a ordem, é combinado, e a descrição do PR do workspace avisa isso. Ao completar para o ramo de teste, desmarque a opção de apagar a branch de origem, porque o PR para o main sai dela. Se apagarem por engano, o /ws-pr-main recria a branch a partir do PR completado. Cada time segue a política de PR do próprio repo. Tempo: 1 min
