## Foco da revisão

Entradas e condições que a spec implica e que mais podem dar errado. Cada uma tem teste na task indicada:

1. **Duas pessoas publicando o Atlas ao mesmo tempo, no mesmo repo.**
   - Esperado: fica a versão de quem publicou antes, o repo volta a ficar pendente e nada é sobrescrito em silêncio.
   - Teste: `test_concluir_mantem_a_versao_de_quem_publicou_antes` (Task 5). A recusa do push durante a corrida usa o mesmo caminho do `ws_atlas_copia`.
2. **PR de `atlas/atualizacao` mergeado com squash** (Azure DevOps permite).

   - Teste: `test_concluir_recomeca_a_branch_depois_de_merge_squash` (Task 5).
3. **Commit gravado que o clone não tem** (fetch raso do `ws start`, ou importado do SP0).
   - Esperado: o plano baixa o commit e compara.
   - Se ele não existe mais no repo (rebase ou force-push): `do-zero` com motivo `split-ausente`.

   - O `concluir` faz commit só de `docs/atlas/` e o resto continua como estava, para o `/speckit-ws-commit-push`.

```bash
#!/usr/bin/env bash
# Importa o mapeamento do SP0 para docs/atlas/ (spec SP2, 6.4, e spec SP3, 6.1 e 6.8).
# Uso: tools/atlas/importa-mapeamento.sh <pasta docs/discovery> [--banco <extract/db-prod>] [--clones <pasta repos/>]
# Copia arquitetura/*, os edges-*.csv da raiz e, de cada repos/<repo>/: domain/, business/, tech/,
# project-readme.md, _discovery/edges.csv (vira <repo>/edges.csv), _discovery/recon-manifest.md e
# _discovery/traceability-index.md. Cria <repo>/_discovery/atlas.estado com o commit do recon.
# Com --banco, copia <db>/dependencies.csv, objects.csv e synonyms.csv para docs/atlas/banco/<db>/.
# Com --clones, expande commits abreviados do recon-manifest pelo clone de mesmo nome.
# Não sobrescreve arquivo que já existe (pode rodar de novo para completar) e recusa arquivos
# com padrão de segredo, listando os recusados.
set -euo pipefail

SEGREDO='(password|pwd)[[:space:]]*=|user id=[^;]*;[[:space:]]*password|BEGIN [A-Z ]*PRIVATE KEY'

src=""
banco=""
clones=""
while [ $# -gt 0 ]; do
  case "$1" in
    --banco) banco=${2:-}; shift 2 ;;
    --clones) clones=${2:-}; shift 2 ;;
    *) src=$1; shift ;;
  esac
done
[ -n "$src" ] || { echo "uso: importa-mapeamento.sh <pasta docs/discovery> [--banco <pasta>] [--clones <pasta>]" >&2; exit 2; }
[ -d "$src/repos" ] && [ -d "$src/arquitetura" ] \
  || { echo "erro: $src não parece a pasta docs/discovery (faltam repos/ ou arquitetura/)" >&2; exit 1; }
[ -z "$banco" ] || [ -d "$banco" ] || { echo "erro: pasta do banco não existe: $banco" >&2; exit 1; }
root=$(git rev-parse --show-toplevel)
dst="$root/docs/atlas"

copiados=0
mantidos=0
recusados=()

# origem destino-relativo-a-docs/atlas
copia() {
  if [ -e "$dst/$2" ]; then
    mantidos=$((mantidos + 1))
    return 0
  fi
  if grep -qiE "$SEGREDO" "$1"; then
    recusados+=("${1#"$src"/}")
    return 0
  fi
  mkdir -p "$(dirname "$dst/$2")"
  cp "$1" "$dst/$2"
  copiados=$((copiados + 1))
}

# manifest repo -> grava <repo>/_discovery/atlas.estado com split= e data= do recon
estado() {
  local man=$1 repo=$2 f="$dst/$2/_discovery/atlas.estado" sha data
  if [ -e "$f" ]; then mantidos=$((mantidos + 1)); return 0; fi
  sha=$(grep -o -m1 'Recon commit:\*\* *`[0-9a-f]*`' "$man" | grep -o '[0-9a-f]\{7,40\}' || true)
  data=$(grep -o -m1 'Last updated:\*\* *[0-9-]*' "$man" | grep -o '[0-9]\{4\}-[0-9-]*' || true)
  if [ -z "$sha" ]; then
    echo "aviso: $repo sem 'Recon commit' no recon-manifest; atlas.estado não criado" >&2
    return 0
  fi
  if [ ${#sha} -lt 40 ] && [ -n "$clones" ] && [ -d "$clones/$repo" ]; then
    sha=$(git -C "$clones/$repo" rev-parse --verify -q "$sha^{commit}" || echo "$sha")
  fi
  [ ${#sha} -eq 40 ] || echo "aviso: $repo com commit abreviado ($sha); o plano vai pedir mapeamento do zero" >&2
  mkdir -p "$(dirname "$f")"
  printf 'split=%s\ndata=%s\n' "$sha" "${data:-$(date +%F)}" > "$f"
  copiados=$((copiados + 1))
}
```

`tools/atlas/plano.py`:

```python
"""Plano de atualização do Atlas (spec SP3, seção 5) e gravação do atlas.estado.

Uso (sempre na raiz do workspace; o ws atlas chama):
  python tools/atlas/plano.py gerar --gatilho start|converge|manual [--repos a,b] [--do-zero]
                                    [--hoje AAAA-MM-DD] [--base main]
  python tools/atlas/plano.py lista --acoes atualizar,do-zero [--sem a,b]
  python tools/atlas/plano.py lista --mudou   (repos cujo commit de origem mudou: os mapas reindexam)
  python tools/atlas/plano.py grava-estado [--falhas a,b] [--hoje AAAA-MM-DD]

O plano fica em .git/atlas-plano.json (git rev-parse --git-path) e também é impresso.
Estado por repo: docs/atlas/<repo>/_discovery/atlas.estado, com linhas split=, arvore= e data=.
"""
import argparse
import configparser
import datetime
import fnmatch
import json
import os
import pathlib
import subprocess
import sys
import tempfile

ACOES_MAPEAR = ('atualizar', 'do-zero')


def git(*args, check=True):
    r = subprocess.run(['git', *args], capture_output=True, text=True, encoding='utf-8', errors='replace')
    if check and r.returncode != 0:
        raise RuntimeError(f'git {" ".join(args)}: {r.stderr.strip()}')
    return r.stdout.strip() if r.returncode == 0 else ''


def caminho_plano():
    return pathlib.Path(git('rev-parse', '--git-path', 'atlas-plano.json'))


def lista_cfg(cfg, secao, chave):
    return [x.strip() for x in cfg.get(secao, chave, fallback='').splitlines() if x.strip()]


def manifesto():
    """Linhas 'prefixo url branch' do workspace.repos, como o ws_manifest."""
    out = []
    for linha in pathlib.Path('workspace.repos').read_text(encoding='utf-8').splitlines():
        p = linha.split()
        if len(p) == 3 and not p[0].startswith('#'):
            out.append((p[0], p[1]))
    return out


def le_estado(repo):
    f = pathlib.Path('docs/atlas') / repo / '_discovery' / 'atlas.estado'
    if not f.exists():
        return None
    e = {}
    for linha in f.read_text(encoding='utf-8').splitlines():
        if '=' in linha:
            k, v = linha.split('=', 1)
            e[k.strip()] = v.strip()
    return e


def split_atual(prefixo):
    sq = git('log', '-1', '--topo-order', '--format=%H', '--all-match',
             f'--grep=^git-subtree-dir: {prefixo}/*$', f"--grep=^Squashed '{prefixo}/' ", 'HEAD', check=False)
    if not sq:
        return ''
    for linha in git('log', '-1', '--format=%b', sq).splitlines():
        if linha.startswith('git-subtree-split:'):
            return linha.split()[1]
    return ''


def arvore_do_split(split, url):
    """Tree do repo no commit gravado; baixa o commit (raso) se ele não estiver no clone."""
    if len(split) != 40:
        return ''
    tem = subprocess.run(['git', 'cat-file', '-e', f'{split}^{{commit}}'], capture_output=True).returncode == 0
    if not tem and subprocess.run(['git', 'fetch', '-q', '--depth=1', url, split], capture_output=True).returncode != 0:
        return ''
    return git('rev-parse', f'{split}^{{tree}}', check=False)


def arvore_da_arvore_de_trabalho(prefixo):
    """Tree do prefixo como está no disco (com o que não foi commitado), por um índice temporário."""
    with tempfile.TemporaryDirectory() as d:
        env = dict(os.environ, GIT_INDEX_FILE=os.path.join(d, 'index'))
        subprocess.run(['git', 'read-tree', 'HEAD'], env=env, check=True, capture_output=True)
        subprocess.run(['git', 'add', '-A', '--', prefixo], env=env, check=True, capture_output=True)
        r = subprocess.run(['git', 'write-tree', f'--prefix={prefixo}/'], env=env, check=True,
                           capture_output=True, text=True)
        return r.stdout.strip()


def linhas_do_diff(base, atual, arquivos):
    """Linhas acrescentadas ou removidas nos arquivos, para procurar as palavras de contrato."""
    if not arquivos:
        return ''
    r = subprocess.run(['git', 'diff', '-U0', base, atual, '--', *arquivos], capture_output=True,
                       text=True, encoding='utf-8', errors='replace')
    return '\n'.join(x for x in r.stdout.splitlines() if x[:1] in '+-' and not x.startswith(('+++', '---')))


def casa(caminho, padroes):
    return any(fnmatch.fnmatchcase(caminho, p) for p in padroes)


def gerar(a):
    cfg = configparser.ConfigParser(interpolation=None)
    cfg.read(pathlib.Path(__file__).with_name('relevancia.ini'), encoding='utf-8')
    pol = cfg['politica']
    ignorar = lista_cfg(cfg, 'ignorar', 'padroes')
    contrato_cam = lista_cfg(cfg, 'contrato', 'caminhos')
    contrato_pal = lista_cfg(cfg, 'contrato', 'palavras')
    hoje = datetime.date.fromisoformat(a.hoje) if a.hoje else datetime.date.today()
    da_feature = {x for x in (a.repos or '').split(',') if x}
    itens = []
    for prefixo, url in manifesto():
        repo = prefixo.split('/', 1)[1]
        est = le_estado(repo)
        sp_atual = split_atual(prefixo)
        arv_atual = git('rev-parse', f'HEAD:{prefixo}', check=False)
        it = {'repo': repo, 'prefixo': prefixo, 'acao': 'nada', 'motivo': '', 'split_atual': sp_atual,
              'arvore_atual': arv_atual, 'split_gravado': (est or {}).get('split', ''), 'mudou': False,
              'arquivos': [], 'areas': [], 'tokens_estimados': 0, 'prioridade': 9}
        itens.append(it)
        if a.gatilho == 'converge':
            # Branch da feature contra o base, contando o que ainda não foi commitado.
            base = git('merge-base', a.base, 'HEAD')
            arqs = git('diff', '--name-only', base, '--', prefixo).splitlines() + \
                git('ls-files', '-o', '--exclude-standard', '--', prefixo).splitlines()
            rel = sorted({x[len(prefixo) + 1:] for x in arqs if x} - {''})
            rel = [x for x in rel if not casa(x, ignorar)]
            if rel:
                it.update(acao='atualizar', motivo='feature', arquivos=rel, arvore_atual=arvore_da_arvore_de_trabalho(prefixo))
            continue
        it['mudou'] = bool(est) and est.get('split') != sp_atual
        if a.do_zero:
            it.update(acao='do-zero', motivo='manual', prioridade=1)
            continue
        if not est:
            it.update(acao='do-zero', motivo='sem-estado', prioridade=1)
            continue
        base = est.get('arvore') or arvore_do_split(est.get('split', ''), url)
        if not base:
            it.update(acao='do-zero', motivo='split-ausente', prioridade=1)
            continue
        if base == arv_atual:
            if it['mudou']:
                it.update(acao='avancar', motivo='sem-mudanca')
            continue
        arqs = [x for x in git('diff', '--name-only', base, arv_atual).splitlines() if x]
        rel = [x for x in arqs if not casa(x, ignorar)]
        it['arquivos'] = rel
        if not rel:
            it.update(acao='avancar', motivo='irrelevante')
            continue
        if a.gatilho == 'manual':
            it.update(acao='atualizar', motivo='manual', prioridade=1)
            continue
        contrato = any(casa(x, contrato_cam) for x in rel) or \
            any(p in linhas_do_diff(base, arv_atual, rel) for p in contrato_pal)
        data = datetime.date.fromisoformat(est.get('data') or '1970-01-01')
        if repo in da_feature:
            it.update(acao='atualizar', motivo='feature', prioridade=0)
        elif contrato:
            it.update(acao='atualizar', motivo='contrato', prioridade=1)
        elif (hoje - data).days >= pol.getint('intervalo_dias'):
            it.update(acao='atualizar', motivo='intervalo', prioridade=2)
        elif len(rel) >= pol.getint('limiar_arquivos'):
            it.update(acao='atualizar', motivo='volume', prioridade=2)
        else:
            it.update(acao='adiar', motivo='interno')
    if a.gatilho == 'start':
        limite = max(pol.getint('limite_minimo'), len(da_feature))
        fila = sorted((x for x in itens if x['acao'] in ACOES_MAPEAR), key=lambda x: (x['prioridade'], x['repo']))
        for x in fila[limite:]:
            x.update(acao='pendente', motivo=x['motivo'] + ',limite')
    for x in itens:
        x['areas'] = sorted({'/'.join(p.split('/')[:2]) for p in x['arquivos']})
        if x['acao'] == 'do-zero':
            x['tokens_estimados'] = pol.getint('tokens_do_zero')
```

```python
"""Gera os derivados do Atlas a partir das arestas de cada repo (spec SP3, 6.5).

Entradas (em docs/atlas/): <repo>/edges.csv de cada repo, edges-sqlagent.csv (jobs do SQL Agent),
banco/<db>/dependencies.csv e objects.csv (catálogo) e procs-escopo.csv.
Saídas em docs/atlas/: edges-consolidado.csv, servico-servico.csv, objetos-compartilhados.csv,
filas.csv, nao-resolvidos.csv, mapa.mmd, grafo.html e o índice de impacto em impacto/.
Uso: python tools/atlas/build-map.py [--raiz <workspace>]
"""
import argparse
import collections
import csv
import pathlib
import re
import subprocess
import sys

import impacto

ap = argparse.ArgumentParser()
ap.add_argument('--raiz', default='.')
ROOT = pathlib.Path(ap.parse_args().raiz).resolve()
OUT = ROOT / 'docs' / 'atlas'
OUT.mkdir(parents=True, exist_ok=True)
CAMPOS = ['repo', 'app', 'tipo', 'alvo', 'detalhe', 'evidencia']


def le_csv(f):
    with open(f, encoding='utf-8-sig', newline='') as h:
        return list(csv.DictReader(h))


# Consolida as arestas por repo (a pasta é o nome do repo) e as dos jobs do banco.
consolidado = []
for f in sorted(OUT.glob('*/edges.csv')):
    for r in le_csv(f):
        r['repo'] = f.parent.name
        consolidado.append({k: r.get(k, '') for k in CAMPOS})
with open(OUT / 'edges-consolidado.csv', 'w', encoding='utf-8', newline='') as h:
    w = csv.DictWriter(h, fieldnames=CAMPOS)
    w.writeheader()
    w.writerows(consolidado)
SRC = [OUT / 'edges-consolidado.csv', OUT / 'edges-sqlagent.csv']


def short(repo):
    if repo == 'sqlagent':
        return 'sqlagent (jobs do banco)'
    repo = repo.replace('industria-logistica.', '')
    return repo.replace('integracoes.core.plataforma.backoffice.frontend', 'fly.backoffice.frontend')


# alvo HTTP -> nó (repo curto ou ext:<nome>). A primeira regra que casa vence.
HTTP_RULES = [
    (r'picking.?front', 'wms.picking.frontend'),
    (r'full picking|picking\.api|wmspickingapi', 'wms.picking.backend'),
    (r'wms3|wms:endpoint|wms:baseurlwms|wmsapi:url|ip interno>:8087|^wms \(httpclient', 'wms.servidor.backend'),
    (r'ecommerce', 'wms.ecommerce.backend'),
    (r'reservanetlinxapi|reservanet-linx-api', 'wms.conector.backend'),
    (r'linxintegration', 'ext:LINX (APIs de integração)'),
    (r'(^|[^a-z])sso|netsso', 'reserva-net.autenticacao.monolito'),  # evita casar 'acesso'
    (r'printer|impressora', 'print-zebra.utilitario.backend'),
    (r'produtividade|hubapi', 'wms.hubprodutividade.backend'),
    (r'trakta', 'wms.trakta.backend'),
    (r'reservanet-b2b-api', 'reserva-net.b2b.backend'),
    (r'awx|checkout|pedidosb2b|pedidosb2c|faturamento|estoque|impressao|erpconnector|reverseproxy'
     r'|recebimento|integracaolegadowms', 'wms.awx.monorepo'),
    (r'intelipost', 'ext:Intelipost'),
    (r'sentry|new relic', 'ext:Observabilidade (Sentry/New Relic)'),
    (r'sendgrid|smtp', 'ext:E-mail (SendGrid/SMTP)'),
    (r'ldap|active directory', 'ext:Active Directory'),
    (r'logistica\.integrada', 'ext:Logistica.Integrada.BFF (Helix, fora do escopo)'),
    (r'ondemand', 'ext:OnDemand (fora do escopo)'),
    (r'reservanet-(queries|commands|tasks|aviamento)', 'ext:ReservaNet (serviços sem repo no workspace)'),
    (r'sftp', 'ext:SFTP transportadoras'),
    (r'genius|trocafacil|troquecommerce', 'ext:Canais de devolução'),
    (r'vtex', 'ext:VTEX'),
    (r'keycloak', 'ext:Keycloak'),
    (r'revopush|codepush', 'ext:Revopush'),
    (r'wkhtmltopdf|arquivo local|compartilhamento de rede', 'ext:Arquivo/processo local'),
    (r'bff intranet|acessible-api|chat-api|gcm|loyalty|prime|faccylita|api principal',
     'ext:Backends não-WMS do Fly'),
]


def resolve_http(alvo):
    a = alvo.lower()
    for pat, node in HTTP_RULES:
        if re.search(pat, a):
            return node
    return 'ext:?' + alvo.strip()[:40]


def norm_queue(alvo):
    a = alvo.lower().split(' ')[0]
    a = re.sub(r'\{?filaatividaderealizada\}?', 'wms-atividade_realizada', a)
    a = re.sub(r'\{?filasessaooperadorregistrada\}?', 'wms-sessao_operador_cluster', a)
    a = re.sub(r'-(dlq|retry.*)$', '', a)
    return re.sub(r'\.integracao-legado$', '', a)  # binding do consumidor na mesma routing key


def norm_db(alvo):
    return re.sub(r'^RESERVA\.', 'Reserva.', alvo.strip()).lower()


rows = [r for f in SRC if f.exists() for r in le_csv(f)]
# Escopo: ONDEMAND fica fora do mapa, exceto objetos do banco WMS (decisão do usuário, 2026-09-24); o CSV de origem não muda.
rows = [r for r in rows if r['alvo'].startswith('WMS.') or not re.search(r'on[ _-]?demand', r['alvo'], re.I)]
pair = collections.defaultdict(lambda: {'n': 0, 'ex': []})
unresolved = []


def add(o, d, via, ex):
    p = pair[(o, d, via)]
    p['n'] += 1
    if len(p['ex']) < 3 and ex and ex not in p['ex']:
        p['ex'].append(ex)


# HTTP e outros destinos de saída
for r in rows:
    if r['tipo'] not in ('http-out', 'other-out'):
        continue
    o, d = short(r['repo']), resolve_http(r['alvo'])
    if d.startswith('ext:?'):
        unresolved.append([o, r['tipo'], r['alvo'], d])
```

```python
"""Índice de impacto do Atlas (spec SP3, 6.5): uma página por objeto com dependentes.

Propagação forte, seguida até o fim: objeto SQL -> views/procs/funções que o referenciam (catálogo)
-> jobs e código que os leem, escrevem ou executam; endpoint -> clientes HTTP; fila -> quem publica
e quem consome. Código e jobs são pontas: a página lista o app atingido e não segue pelos
endpoints e filas dele (propagação fraca; quem decide é o agente).
Chamado pelo build-map.py: impacto.gera(pasta_atlas, arestas, resolve_http, norm_queue, norm_db).
"""
import collections
import csv
import re
import shutil

LIMITE_PAGINA = 50  # acima disso a página resume por repo; calibrado no PoC (p90 = 24 afetados)
TIPOS_SQL = {'U': 'tabela', 'V': 'view', 'P': 'procedure', 'FN': 'função', 'IF': 'função', 'TF': 'função',
             'TR': 'trigger', 'SN': 'sinônimo'}
METODO = re.compile(r'\b(GET|POST|PUT|DELETE|PATCH)\s+/?([^\s(]+)', re.I)


def _csv(f):
    with open(f, encoding='utf-8-sig', newline='') as h:
        return list(csv.DictReader(h))


def _slug(chave):
    return re.sub(r'[^a-z0-9._-]+', '-', chave.lower()).strip('-')[:150]


def _segmentos(caminho):
    seg = [s for s in caminho.lower().split('?')[0].strip('/').split('/') if s]
    if seg and seg[0] == 'api':
        seg = seg[1:]
    return ['*' if s.startswith('{') or s.startswith(':') else s for s in seg]


def _casa_rota(rota, chamada):
    a, b = _segmentos(rota), _segmentos(chamada)
    return len(a) == len(b) and len(a) > 0 and all(x == '*' or y == '*' or x == y for x, y in zip(a, b))


class Grafo:
    def __init__(self):
        self.dep = collections.defaultdict(dict)   # x -> {dependente: info}
        self.meta = {}                             # chave -> {nome, tipo, grupo, ponta}

    def no(self, chave, nome, tipo, grupo, ponta=False):
        self.meta.setdefault(chave, {'nome': nome, 'tipo': tipo, 'grupo': grupo, 'ponta': ponta})

    def liga(self, x, y, acesso, evidencia=''):
        if x == y:
            return
        info = self.dep[x].setdefault(y, {'acesso': set(), 'ev': []})
        info['acesso'].add(acesso)
        if evidencia and len(info['ev']) < 3 and evidencia not in info['ev']:
            info['ev'].append(evidencia)


def _catalogo(g, atlas):
    fora = set()
    if (atlas / 'procs-escopo.csv').exists():
        fora = {f"{r['db']}.{r['schema']}.{r['proc']}".lower() for r in _csv(atlas / 'procs-escopo.csv')
                if r.get('escopo') == 'fora'}
    tipos = {}
    for f in atlas.glob('banco/*/objects.csv'):
        db = f.parent.name
        for r in _csv(f):
            tipos[f"{db}.{r['schema']}.{r['name']}".lower()] = TIPOS_SQL.get(r['type'].strip(), r['type'].strip())
    for f in atlas.glob('banco/*/dependencies.csv'):
        db = f.parent.name
        for r in _csv(f):
            if not r.get('to_name') or r['to_name'].lower() in ('inserted', 'deleted'):
                continue
            de = f"{db}.{r['from_schema'] or 'dbo'}.{r['from_name']}"
            para = f"{r['to_db'] or db}.{r['to_schema'] or r['from_schema'] or 'dbo'}.{r['to_name']}"
            kde, kpara = de.lower(), para.lower()
            if kde in fora or kpara in fora:
                continue
            g.no(kpara, para, tipos.get(kpara, 'objeto SQL'), 'banco ' + para.split('.')[0])
            g.no(kde, de, tipos.get(kde, 'objeto SQL'), 'banco ' + de.split('.')[0])
            g.liga(kpara, kde, 'referência SQL')
    for f in atlas.glob('banco/*/synonyms.csv'):
        db = f.parent.name
        for r in _csv(f):
            if not r.get('to_name'):
                continue
            sin = f"{db}.{r['schema']}.{r['name']}"
            alvo = f"{r['to_db'] or db}.{r['to_schema'] or 'dbo'}.{r['to_name']}"
            g.no(alvo.lower(), alvo, tipos.get(alvo.lower(), 'objeto SQL'), 'banco ' + alvo.split('.')[0])
            g.no(sin.lower(), sin, 'sinônimo', 'banco ' + db)
            g.liga(alvo.lower(), sin.lower(), 'sinônimo')
    return tipos


def _arestas(g, linhas, tipos, resolve_http, norm_queue, norm_db):
    rotas = []
    for r in linhas:
        repo, tipo = r['repo'], r['tipo']
        if repo == 'sqlagent':
            m = re.search(r'job "([^"]+)"', r.get('detalhe', ''))
            dono = 'job:' + (m.group(1) if m else r['app'])
            g.no(dono, dono[4:], 'job do SQL Agent', 'sqlagent (jobs do banco)', ponta=True)
        else:
            dono = 'repo:' + repo
            g.no(dono, repo, 'código', repo, ponta=True)
        if tipo.startswith('db-'):
            k = norm_db(r['alvo'])
            g.no(k, r['alvo'].strip(), tipos.get(k, 'objeto SQL'), 'banco ' + r['alvo'].strip().split('.')[0])
            g.liga(k, dono, tipo, r.get('evidencia', ''))
        elif tipo in ('mq-pub', 'mq-sub'):
            q = norm_queue(r['alvo'])
            g.no('fila:' + q, q, 'fila', 'filas')
            g.liga('fila:' + q, dono, tipo, r.get('evidencia', ''))
        elif tipo == 'http-in':
            m = METODO.search(r.get('detalhe', ''))
            if m:
                rota = f'{m.group(1).upper()} /{m.group(2)}'
                k = f'http:{repo}:{rota}'.lower()
                g.no(k, f'{repo} {rota}', 'endpoint', repo)
                rotas.append((repo, m.group(1).upper(), m.group(2), k))
    curto = {}
    for repo, _, _, _ in rotas:
        curto[repo] = repo.replace('industria-logistica.', '').replace(
            'integracoes.core.plataforma.backoffice.frontend', 'fly.backoffice.frontend')
    for r in linhas:
        if r['tipo'] != 'http-out':
            continue
        destino = resolve_http(r['alvo'])
        alvo = r['alvo'].strip().lower()
        m = METODO.search(r.get('detalhe', ''))
        if not m:
            continue
        for repo, met, caminho, k in rotas:
            # o alvo resolve para o repo pelas regras do build-map, ou já é o nome do repo
            e_o_repo = destino == curto[repo] or alvo in (repo.lower(), curto[repo].lower())
            if e_o_repo and repo != r['repo'] and met == m.group(1).upper() and _casa_rota(caminho, m.group(2)):
                g.liga(k, 'repo:' + r['repo'], 'http-out', r.get('evidencia', ''))


def _busca(g, origem):
    dist, pai = {origem: 0}, {origem: None}
    fila = collections.deque([origem])
    while fila:
        x = fila.popleft()
        if g.meta.get(x, {}).get('ponta'):
            continue
        for y in g.dep.get(x, {}):
            if y not in dist:
                dist[y], pai[y] = dist[x] + 1, x
                fila.append(y)
    return dist, pai


def _ciclos(g):
    """Componentes fortemente conexos com mais de um nó (Tarjan iterativo), só entre não-pontas."""
    idx, low, pilha, na_pilha, comps, c = {}, {}, [], set(), [], [0]
    nos = [n for n in g.meta if not g.meta[n]['ponta']]
    for v0 in nos:
        if v0 in idx:
            continue
        trilha = [(v0, iter(sorted(g.dep.get(v0, {}))))]
        idx[v0] = low[v0] = c[0]; c[0] += 1; pilha.append(v0); na_pilha.add(v0)
        while trilha:
            v, it = trilha[-1]
            for w in it:
                if g.meta.get(w, {}).get('ponta'):
                    continue
                if w not in idx:
                    idx[w] = low[w] = c[0]; c[0] += 1; pilha.append(w); na_pilha.add(w)
                    trilha.append((w, iter(sorted(g.dep.get(w, {})))))
                    break
                if w in na_pilha:
                    low[v] = min(low[v], idx[w])
            else:
                trilha.pop()
                if trilha:
                    low[trilha[-1][0]] = min(low[trilha[-1][0]], low[v])
                if low[v] == idx[v]:
                    comp = []
                    while True:
                        w = pilha.pop(); na_pilha.discard(w); comp.append(w)
                        if w == v:
                            break
                    if len(comp) > 1:
                        comps.append(sorted(comp))
    return comps


def _linha(g, origem, y, dist, pai):
    caminho, z = [], y
    while z is not None:
        caminho.append(g.meta[z]['nome'])
        z = pai[z]
    info = g.dep[pai[y]][y]
    ev = ', '.join(f'`{e}`' for e in info['ev'])
    via = ' ← '.join(reversed(caminho[1:-1])) if len(caminho) > 2 else 'direto'
    return (f"- {g.meta[y]['nome']} ({g.meta[y]['tipo']}) — distância {dist[y]}, via {via}; "
            f"{', '.join(sorted(info['acesso']))}{'; ' + ev if ev else ''}")


def gera(atlas, linhas, resolve_http, norm_queue, norm_db):
    g = Grafo()
    tipos = _catalogo(g, atlas)
    _arestas(g, linhas, tipos, resolve_http, norm_queue, norm_db)
    ciclos = _ciclos(g)
    ciclo_de = {n: i + 1 for i, comp in enumerate(ciclos) for n in comp}
    pasta = atlas / 'impacto'
    shutil.rmtree(pasta, ignore_errors=True)
    pasta.mkdir(parents=True)
    with open(pasta / 'ciclos.csv', 'w', encoding='utf-8', newline='') as h:
        w = csv.writer(h)
        w.writerow(['ciclo', 'membros'])
        for i, comp in enumerate(ciclos, 1):
            w.writerow([i, ';'.join(g.meta[n]['nome'] for n in comp)])
    indice = []
    for origem in sorted(g.dep):
        if g.meta[origem]['ponta'] or not g.dep[origem]:
            continue
        dist, pai = _busca(g, origem)
        afetados = sorted((y for y in dist if y != origem), key=lambda y: (g.meta[y]['grupo'], dist[y], g.meta[y]['nome']))
        grupos = collections.defaultdict(list)
        for y in afetados:
            grupos[g.meta[y]['grupo']].append(y)
        arq = _slug(origem) + '.md'
        m = g.meta[origem]
        cab = [f"# Impacto: {m['nome']}", '',
               f"Tipo: {m['tipo']} · Afetados: {len(afetados)} · Profundidade máxima: {max(dist.values())}", '',
               'Propagação forte até o fim. Código e jobs são pontas: se o contrato de um app atingido mudar, '
               'abra a página do endpoint ou da fila dele.', '']
        corpo = ['## Por repo', '']
        for grupo in sorted(grupos):
            corpo += [f'### {grupo}', ''] + [_linha(g, origem, y, dist, pai) for y in grupos[grupo]] + ['']
        tocados = sorted({ciclo_de[n] for n in [origem, *afetados] if n in ciclo_de})
        rodape = []
        if tocados:
            rodape = ['## Ciclos', '', 'Mudar um membro de um ciclo afeta o ciclo inteiro.', '']
            rodape += [f"- Ciclo {i}: {' → '.join(g.meta[n]['nome'] for n in ciclos[i - 1])}" for i in tocados] + ['']
        if len(afetados) > LIMITE_PAGINA:

            resumo += [f'- {grupo}: {len(ys)} afetado(s), distância mínima {min(dist[y] for y in ys)}'
                       for grupo, ys in sorted(grupos.items())] + ['']
            texto = cab + resumo + rodape
        else:
            texto = cab + corpo + rodape
        (pasta / arq).write_text('\n'.join(texto), encoding='utf-8')
        indice.append([m['nome'], m['tipo'], arq, len(afetados), max(dist.values())])
```

```bash
# Traz para a branch atual o que está em atlas/atualizacao e ainda não entrou nela.
ws_atlas_incorpora() {
  has_origin || { log "sem origin; nada a incorporar"; return 0; }
  git fetch -q origin "+refs/heads/$WS_ATLAS_BRANCH:refs/remotes/origin/$WS_ATLAS_BRANCH" 2>/dev/null \
    || { log "$WS_ATLAS_BRANCH ainda não existe no origin; nada a incorporar"; return 0; }
  if git merge-base --is-ancestor "origin/$WS_ATLAS_BRANCH" HEAD; then
    log "$WS_ATLAS_BRANCH já está em $(current_branch)"
    return 0
  fi
  ws_atlas_merge "incorporada"
}

# mensagem -> merge de origin/atlas na branch atual. Conflito não para a feature: cancela e avisa.
ws_atlas_merge() {
  if git merge -q --no-edit "origin/$WS_ATLAS_BRANCH" >/dev/null 2>&1; then
    log "$WS_ATLAS_BRANCH $1 em $(current_branch)"
  else
    git merge --abort 2>/dev/null || true
    log "aviso: conflito ao trazer $WS_ATLAS_BRANCH para $(current_branch); a feature segue com os docs do $WS_BASE"
  fi
}

# Arquivos alterados ou novos em docs/atlas com padrão de segredo: saem da árvore e são listados.
ws_atlas_filtra_segredos() {
  local f achou=0
  while IFS= read -r f; do
    [ -f "$f" ] || continue
    grep -qiE "$WS_ATLAS_SEGREDO" "$f" || continue
    [ $achou -eq 1 ] || log "aviso: arquivos com padrão de segredo, fora do commit:"
    achou=1
    echo "  $f"
    if git cat-file -e "HEAD:$f" 2>/dev/null; then git checkout -q HEAD -- "$f"; else rm -f "$f"; fi
  done < <(git ls-files -m -o --exclude-standard -- docs/atlas)
}

# ws atlas concluir --gatilho start|converge|manual [--falhas a,b]
# Grava o atlas.estado dos repos do plano, regenera os derivados e:
# - converge: commit na branch atual (o push vai com a feature);
# - start e manual: commit em atlas/atualizacao, push e merge na branch atual.
ws_atlas_concluir() {
  local gatilho="" falhas="" repos
  while [ $# -gt 0 ]; do
    case "$1" in
      --gatilho) gatilho=${2:-}; shift 2 ;;
      --falhas) falhas=${2:-}; shift 2 ;;
      *) die "argumento desconhecido: $1" ;;
    esac
  done
  case "$gatilho" in
    start|converge|manual) ;;
    *) die "uso: ws atlas concluir --gatilho start|converge|manual [--falhas a,b]" ;;
  esac
  repos=$(ws_atlas_py plano.py grava-estado --falhas "$falhas" | tr -d '\r' | paste -sd' ' -)
  [ -z "$falhas" ] || log "aviso: o mapeamento falhou em ${falhas//,/, }; esses repos continuam pendentes"
  ws_atlas_py build-map.py >/dev/null
  ws_atlas_filtra_segredos
  if [ -z "$(git status --porcelain -- docs/atlas)" ]; then
    log "atlas sem mudanças"
    return 0
  fi
  if [ "$gatilho" = converge ]; then
    git add -A docs/atlas
    git commit -qm "atlas: atualiza mapeamento de ${repos:-derivados}"
    log "atlas atualizado em $(current_branch)"
    return 0
  fi
  ws_atlas_publica "$repos"
}

# Base da publicação: a branch atlas do origin enquanto o PR dela não entrou no base; depois do
# merge (normal ou squash), o base.
ws_atlas_base() {
  local r="origin/$WS_ATLAS_BRANCH"
  git rev-parse -q --verify "$r" >/dev/null || { echo "origin/$WS_BASE"; return; }
  if git merge-base --is-ancestor "$r" "origin/$WS_BASE" || git diff --quiet "origin/$WS_BASE" "$r" -- docs/atlas; then
    echo "origin/$WS_BASE"
  else
    echo "$r"
  fi
}

# "repos" -> commit em atlas/atualizacao num worktree temporário, push (até 3 tentativas) e merge
# na branch atual.
ws_atlas_publica() {
  local repos=$1 wt base remoto lease=() tentativa
  wt=$(git rev-parse --git-path atlas-wt)
  git fetch -q origin "$WS_BASE"
  git fetch -q origin "+refs/heads/$WS_ATLAS_BRANCH:refs/remotes/origin/$WS_ATLAS_BRANCH" 2>/dev/null || true
  remoto=$(git rev-parse -q --verify "origin/$WS_ATLAS_BRANCH" || true)
  base=$(ws_atlas_base)
  # PR anterior já mergeado: a branch recomeça do base; com merge squash isso não é fast-forward.
  [ -z "$remoto" ] || [ "$base" != "origin/$WS_BASE" ] || lease=(--force-with-lease="$WS_ATLAS_BRANCH:$remoto")
  git worktree remove --force "$wt" 2>/dev/null || rm -rf "$wt"
  git worktree prune
  git worktree add -q --detach "$wt" "$base"
  for tentativa in 1 2 3; do
    ws_atlas_copia "$wt" "$base" "$repos" || break
    if git -C "$wt" push -q "${lease[@]}" origin "HEAD:refs/heads/$WS_ATLAS_BRANCH" 2>/dev/null; then
      break
    fi
    if [ "$tentativa" -eq 3 ]; then
      git worktree remove --force "$wt"
      die "push de $WS_ATLAS_BRANCH recusado 3 vezes; rode ws atlas concluir de novo"
    fi
    log "push de $WS_ATLAS_BRANCH recusado; refazendo sobre o origin"
    git fetch -q origin "+refs/heads/$WS_ATLAS_BRANCH:refs/remotes/origin/$WS_ATLAS_BRANCH"
    base="origin/$WS_ATLAS_BRANCH"
    lease=()
    git -C "$wt" checkout -q --detach "$base"
  done
  git worktree remove --force "$wt"
  git checkout -q HEAD -- docs/atlas 2>/dev/null || true
  git clean -fdq -- docs/atlas
  if ! git fetch -q origin "+refs/heads/$WS_ATLAS_BRANCH:refs/remotes/origin/$WS_ATLAS_BRANCH" 2>/dev/null; then
    log "atlas sem mudanças a publicar"
    return 0
  fi
  git merge-base --is-ancestor "origin/$WS_ATLAS_BRANCH" HEAD || ws_atlas_merge "publicada e incorporada"
  [ -n "$remoto" ] || log "abra o PR: $(git remote get-url origin)/pullrequestcreate?sourceRef=$WS_ATLAS_BRANCH&targetRef=$WS_BASE"
  ws_atlas_aviso_pr
}

# worktree base "repos" -> copia docs/atlas/<repo>/ da árvore atual para o worktree, regenera os
# derivados lá e faz o commit; falha (código 1) se não houver nada a publicar. Repo que outra
# pessoa atualizou no base depois da versão que esta branch tem fica com a versão dela e volta a
# ficar pendente.
ws_atlas_copia() {
  local wt=$1 base=$2 r comum manter="" copiados=""
  comum=$(git merge-base HEAD "$base")
  for r in $3; do
    if ! git diff --quiet "$comum" "$base" -- "docs/atlas/$r"; then
      manter="$manter $r"
      continue
    fi
    rm -rf "${wt:?}/docs/atlas/$r"
    mkdir -p "$wt/docs/atlas"
    [ ! -d "docs/atlas/$r" ] || cp -r "docs/atlas/$r" "$wt/docs/atlas/$r"
    copiados="$copiados $r"
  done
  [ -z "$manter" ] || log "aviso: outra pessoa atualizou$manter em $WS_ATLAS_BRANCH antes; fica a versão dela e o repo volta a ficar pendente"
  python "$(ws_atlas_tools)/build-map.py" --raiz "$wt" >/dev/null
  git -C "$wt" add -A docs/atlas
  if git -C "$wt" diff --cached --quiet; then return 1; fi
  git -C "$wt" commit -qm "atlas: atualiza mapeamento de${copiados:- derivados}"
}

ws_atlas_aviso_pr() {
  local n idade max_c max_d
  max_c=$(ws_atlas_cfg pr_max_commits)
  max_d=$(ws_atlas_cfg pr_max_dias)
  n=$(git rev-list --count "origin/$WS_BASE..origin/$WS_ATLAS_BRANCH")
  [ "$n" -gt 0 ] || return 0
  idade=$(( ( $(date +%s) - $(git log --reverse --format=%ct "origin/$WS_BASE..origin/$WS_ATLAS_BRANCH" | head -1) ) / 86400 ))
  if [ "$n" -gt "$max_c" ] || [ "$idade" -gt "$max_d" ]; then
    log "aviso: o PR de $WS_ATLAS_BRANCH acumula $n commit(s) e $idade dia(s); peça a aprovação para ele não divergir do $WS_BASE"
  fi
}
```

```bash
# Mapas estruturais do nível 2 (spec SP3, 6.7): codebase-memory-mcp (no WSL) e Graphify (só AST).
# ws atlas mapas [--repos a,b | --todos]: atualiza os mapas dos repos indicados (padrão: os que
# mudaram no último plano) conforme docs/atlas/ferramentas-por-repo.yml; falha de um mapa só avisa.
ws_atlas_mapas() {
  local repos="" todos=0 r prefix url branch grafos=() falhou=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --repos) repos=${2:-}; shift 2 ;;
      --todos) todos=1; shift ;;
      *) die "uso: ws atlas mapas [--repos a,b | --todos]" ;;
    esac
  done
  if [ $todos -eq 1 ]; then
    repos=$(ws_manifest | awk '{ sub(/^repos\//, "", $1); print $1 }' | paste -sd, -)
  elif [ -z "$repos" ]; then
    repos=$(ws_atlas_py plano.py lista --mudou | tr -d '\r' | paste -sd, -)
  fi
  for r in ${repos//,/ }; do
    [ -d "repos/$r" ] || { log "aviso: repos/$r não existe; mapa ignorado"; continue; }
    if [ "$(ws_atlas_mapa_de "$r")" = graphify ]; then
      GRAPHIFY_NO_AUTO_REFRESH=1 ws_graphify update "repos/$r" >/dev/null 2>&1 || falhou="$falhou $r"
    else
      ws_cbm cli --quiet index_repository --repo-path "$(ws_atlas_caminho_wsl "repos/$r")" --name "$r" >/dev/null 2>&1 \
        || falhou="$falhou $r"
    fi
  done
  while read -r prefix url branch; do
    r=${prefix#repos/}
    [ "$(ws_atlas_mapa_de "$r")" = graphify ] && [ -f "$prefix/graphify-out/graph.json" ] && grafos+=("$prefix/graphify-out/graph.json")
  done < <(ws_manifest)
  if [ ${#grafos[@]} -gt 0 ]; then
    mkdir -p .ws/graphify
    if [ ${#grafos[@]} -eq 1 ]; then
      cp "${grafos[0]}" .ws/graphify/frontends.json
    else
      GRAPHIFY_NO_AUTO_REFRESH=1 ws_graphify merge-graphs "${grafos[@]}" --out .ws/graphify/frontends.json >/dev/null 2>&1 \
        || falhou="$falhou graphify-merge"
    fi
  fi
  [ -z "$falhou" ] || log "aviso: mapa não atualizado em$falhou; o agente usa grep e ast-grep nesses repos"
  [ -z "$repos" ] || log "mapas atualizados: ${repos//,/, }"
}

# repo -> cbm ou graphify, pelo docs/atlas/ferramentas-por-repo.yml (padrão: cbm)
ws_atlas_mapa_de() {
  local f=docs/atlas/ferramentas-por-repo.yml m=""
  [ ! -f "$f" ] || m=$(tr -d '\r' < "$f" | awk -F: -v r="$1" '{ gsub(/ /, "", $1); gsub(/ /, "", $2) } $1 == r { print $2 }')
  echo "${m:-cbm}"
}

# caminho do workspace -> o mesmo caminho visto do WSL (/mnt/c/...)
ws_atlas_caminho_wsl() {
  local w
  w=$(cygpath -m "$(pwd)/$1")
  echo "/mnt/$(echo "${w:0:1}" | tr '[:upper:]' '[:lower:]')${w:2}"
}

ws_cbm() {
  if [ -n "${WS_CBM:-}" ]; then $WS_CBM "$@"; return; fi
  # MSYS_NO_PATHCONV: o Git Bash não converte os caminhos /mnt/... passados ao wsl.exe.
  MSYS_NO_PATHCONV=1 wsl.exe -d "${WS_CBM_DISTRO:-Ubuntu}" -- "~/.local/bin/codebase-memory-mcp" "$@"
}

ws_graphify() {
  if [ -n "${WS_GRAPHIFY:-}" ]; then $WS_GRAPHIFY "$@"; return; fi
  graphify "$@"
}
```

```bash
# Instala o codebase-memory-mcp (versão fixada) no WSL, para o mapa estrutural do nível 2 (spec SP3, 6.7).

trap 'rm -rf "$tmp"' EXIT
```

```markdown
Entrada: `--gatilho start|converge|manual` (padrão `manual`), `--repos a,b` (repos prováveis da feature, no start) e `--do-zero` (só no manual).

## 1. Preparar a branch

- **start:** você já está na branch da feature, criada pelo `ws start`. Rode `tools/ws/ws atlas incorpora`.
- **converge:** você está na branch da feature. Nada a preparar.
- **manual:** rode `tools/ws/ws start atlas/manual-$(date +%Y%m%d%H%M)` e depois `tools/ws/ws atlas incorpora`. A branch é descartável: no fim, volte ao `main` e apague-a com `git branch -D`.

## 2. Plano

Rode `tools/ws/ws atlas plano --gatilho <gatilho> [--repos <a,b>] [--do-zero]` e leia o JSON:
- repos com `acao` `atualizar` ou `do-zero` serão mapeados agora;
- `adiar`, `pendente` e `avancar` não usam LLM.

Mostre ao usuário, numa tabela curta, os repos a mapear, o motivo e o `tokens_estimados` de cada um, e o total.
- **`--do-zero`:** peça confirmação antes de seguir, porque o custo fica na casa dos milhões de tokens.
- **Outros gatilhos:** siga sem pedir confirmação.

Se nenhum repo for mapeado, pule para o passo 4.

## 3. Mapear

Para cada repo a mapear, despache um subagente com o prompt de `tools/atlas/prompt-mapeamento.md`, preenchendo:
- `<REPO>` com o repo;
- `<MODO>` com `incremental` (ação `atualizar`) ou `do-zero`;
- `<SPLIT>` com o `split_atual`;
- `<AREAS>` e `<ARQUIVOS>` com o que o plano listou.

Rode até 4 subagentes em paralelo.

Junte os repos cujo relatório disser **FALHOU**, ou cujo subagente não terminou, numa lista separada por vírgulas.

## 4. Concluir

Rode `tools/ws/ws atlas concluir --gatilho <gatilho> [--falhas <lista>]` e mostre os avisos:
- **segredo:** arquivo deixado de fora;
- **falha:** o repo continua pendente;
- **outra pessoa atualizou antes:** o repo volta a ficar pendente;
- **conflito no merge:** a feature segue com os docs do `main`;
- **PR acumulado:** peça a aprovação do PR de `atlas/atualizacao`.

Se aparecer "abra o PR", passe o link ao usuário: o PR de `atlas/atualizacao` é aberto e mergeado à mão.

## 5. Mapas do nível 2

- **start e manual:** rode `tools/ws/ws atlas mapas`, que reindexa os mapas dos repos cujo commit mudou.
- **converge:** pule este passo.

Falha de mapa só avisa.

## 6. Fim

- **manual:** `git checkout main` e `git branch -D atlas/manual-...`.
- **start:** devolva o controle ao `/speckit-specify`.
- **converge:** devolva o controle ao hook do `converge`.
```

```markdown
# Consultar o Atlas

O Atlas fica em `docs/atlas/`. Leia só o que a pergunta pede; nunca carregue o Atlas inteiro no contexto.

## Nível 1: entre repos

| Pergunta | Onde |
|---|---|
| Quem fala com quem (HTTP, filas, banco) | `docs/atlas/mapa-arquitetura.md` (narrativo) e `docs/atlas/servico-servico.csv` |
| O que um repo faz, regras, fluxos, integrações | `docs/atlas/<repo>/` (`domain/`, `business/`, `tech/integrations.md`) |
| Se eu mudar o objeto Z, quem é afetado | `docs/atlas/impacto/indice.csv` → a página indicada |
| Objetos tocados por mais de um repo | `docs/atlas/objetos-compartilhados.csv` |
| Filas, publicadores e consumidores | `docs/atlas/filas.csv` |

**Impacto, passo a passo:**
1. `grep -i "<nome do objeto>" docs/atlas/impacto/indice.csv`. Tabelas, views e procs aparecem como `banco.schema.objeto`; endpoints como `<repo> <MÉTODO> /rota`; filas pelo nome.
2. Abra a página da coluna `pagina` em `docs/atlas/impacto/`. Ela traz os afetados por repo, a distância, o caminho mais curto e a evidência (`arquivo:linha`).
3. **Propagação forte** (definição SQL, endpoint → cliente, fila → pub/sub) vai até o fim. Na spec e no plano, cada dependente forte vira tarefa ou risco explícito.
4. **Código e jobs são pontas:** a página lista o app atingido e para. Se a mudança alterar o contrato desse app (um endpoint ou uma fila dele), abra a página daquele endpoint ou fila e siga. Na dúvida, registre como ponto a confirmar.
5. Seção **Ciclos**: mudar um membro afeta o ciclo inteiro; diga isso no plano.
6. Página com **Resumo por repo**: abra o `.completo.md` só para os repos que importam.

**Feature nova, quais repos mudam:**
1. Ache os conceitos de negócio nos glossários: `grep -ril "<termo>" docs/atlas/*/domain/`.
2. Leia `tech/integrations.md` dos repos candidatos.
3. Confira os contratos tocados no índice de impacto.
4. Preencha "Repos afetados" dizendo o que muda em cada um.

**Desatualização:** se o `project-readme.md` de um repo tiver o aviso de mapeamento pendente, diga ao usuário que os docs daquele repo podem estar defasados nas áreas citadas.

## Ponte para o código

Uma regra ou fluxo dos docs leva ao código por `docs/atlas/<repo>/_discovery/traceability-index.md`, que liga cada afirmação a `arquivo:linha`. Comece a leitura por ali.

## Nível 2: dentro de um repo

`docs/atlas/ferramentas-por-repo.yml` diz o mapa de cada repo (`cbm` ou `graphify`).

- **`cbm`** (MCP `codebase-memory`, projeto = nome do repo):
  - `trace_path` (quem chama X, o que X chama; `--direction inbound|outbound`);
  - `get_code_snippet` (código de um símbolo; se vier `ambiguous`, repita com o `qualified_name` sugerido);
  - `search_code` (busca textual ranqueada);
  - `search_graph` e `query_graph` (Cypher; arestas `CALLS`, `IMPLEMENTS`, `INHERITS`, `USAGE`).
- **`graphify`** (MCP `graphify-frontends`, frontends): `get_node`, `get_neighbors` (quem importa ou usa um service ou componente), `shortest_path` e `query_graph`. Nome ambíguo: use `caminho::símbolo`.
- **Edição:** ferramentas padrão (Read, Edit) e `ast-grep` para busca ou troca estrutural (`ast-grep run -p '<padrão>' -l csharp repos/<repo>`).
- **Mapa fora do ar** (WSL desligado, MCP sem resposta): use grep e ast-grep e avise.
- **SQL:** a dependência entre procs e tabelas vem do índice de impacto (catálogo do banco), não dos `.sql` dos repos.
```
